Local REST API Quick Reference

All mutations require loopback origin; cross-origin browser requests are strictly rejected.

# Get daemon health & freshness SLI curl -s http://127.0.0.1:8080/v1/status | jq # List all checks curl -s http://127.0.0.1:8080/v1/checks | jq # Trigger manual run for a check curl -X POST http://127.0.0.1:8080/v1/checks/price-tracker/run # Approve a verified repair (requires human signature) curl -X POST http://127.0.0.1:8080/v1/incidents/inc-1/approve \ -H "Content-Type: application/json" \ -d '{"by": "senior-engineer", "reason": "verified layout shift"}'
