REST API Specification

Agentd serves an authenticated, loopback-bound REST API under /v1/.... By default, it listens at http://127.0.0.1:8080.

Security & Cross-Origin Invariants

To protect against DNS rebinding and drive-by web attacks:
• Requests with Sec-Fetch-Site: cross-site are rejected with 403 Forbidden.
• External non-loopback Origin headers and opaque null origins are blocked.
• Mutation endpoints enforce a 4 MiB request body cap via http.MaxBytesReader.

System & Health Endpoints

GET /v1/status

Retrieves the overall daemon health, observation freshness SLI, and queue metrics.

// Response (200 OK) { "healthy": true, "checks_total": 42, "checks_active": 40, "fresh_count": 39, "overdue_count": 1, "max_staleness_seconds": 128.5, "active_runs": 2, "queue_depth": 0, "open_incidents": 1 }

Observation Check Endpoints

GET /v1/checks

Lists all configured checks with their active definitions and schedules.

POST /v1/checks

Creates or updates an observation check with defined semantic intent and locator binding.

// Request Body { "id": "price-tracker", "name": "Production Price Check", "source": { "kind": "http", "url": "https://example.com/item" }, "intent": { "kind": "scalar", "scalar": { "name": "price", "type": "currency" } }, "binding": { "kind": "css", "locator": ".price-box span.val" }, "schedule": { "interval": "1h", "jitter": "5m", "catch_up": "once" }, "enabled": true }
POST /v1/checks/{id}/run

Triggers an immediate out-of-schedule run for the specified check.

Execution Run Endpoints

GET /v1/runs

Returns historical execution runs with durations, terminal states, and triage verdicts.

Breakage Incident & Repair Endpoints

GET /v1/incidents

Lists open and resolved incidents, root cause classifications, and candidate repairs.

POST /v1/incidents/{id}/approve

Approves and activates a verified repair candidate. Requires operator attribution signature.

// Request Body (Mandatory "by" field) { "by": "alice", "reason": "Verified layout shift on redesigned product page" }

Maintenance Endpoints

POST /v1/gc

Executes an atomic retention sweep, removing expired snapshots and non-terminal runs while retaining known-good snapshots.

POST /v1/backup

Creates a consistent, checkpointed SQLite snapshot file with 0600 file permissions.

GET /metrics

Exposes Prometheus format metrics including run counts, durations, and freshness SLIs.
