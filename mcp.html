Model Context Protocol (MCP) Guide

Agentd implements the Model Context Protocol (MCP), enabling autonomous AI agents (Claude Desktop, Cursor, Antigravity) to query web observations, inspect breakages, and analyze extraction health.

Security Invariant: Read-Only Tool Isolation

MCP tools exposed by Agentd are strictly read-only. Any attempt by an external AI agent to invoke write operations (e.g. approve_repair, add_check, delete_check) over MCP is rejected with a security boundary violation error. Human operator approval cannot be delegated to an AI agent.

1. Configuring Claude Desktop

Add Agentd to your claude_desktop_config.json:

{ "mcpServers": { "agentd": { "command": "/usr/local/bin/agentd", "args": ["mcp", "--db", "/var/lib/agentd/agentd.db"] } } }

2. Running Over Stdio

For interactive CLI scripting or language model integration pipelines, run:

# Start MCP server listening on standard input/output: agentd mcp

3. Running Over HTTP POST

When Agentd is running as a daemon via agentd serve, MCP JSON-RPC messages can be sent to POST /v1/mcp:

curl -X POST http://127.0.0.1:8080/v1/mcp \ -H "Content-Type: application/json" \ -d '{ "jsonrpc": "2.0", "id": 1, "method": "tools/call", "params": { "name": "inspect_status", "arguments": {} } }'

4. The 7 Inspection Tools

1. inspect_status

Returns daemon health, freshness SLIs, and active worker counts.

2. list_checks

Enumerates all configured checks, intent types, and intervals.

3. inspect_check

Detailed specification of a single check: active binding, intent, and source configuration.

4. list_runs

Recent execution history including terminal states and duration.

5. inspect_run

Deep inspection of a single run: extracted payload, diff against previous, and model triage reason.

6. list_incidents

All open and historical incidents requiring human operator intervention.

7. inspect_incident

Root cause analysis, broken DOM locator, candidate repair locator, and 5-gate sanity scores.
