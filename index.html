Engineered for Absolute Reliability

Why production systems choose Agentd over fragile scrapers and blind LLM agents.

Pure Static Binary
Single standalone executable. Zero runtime dependencies, no cgo, no node, and no external database servers. Runs natively on Linux, macOS, and Windows.
100% Hash-Gated Triage
Canonical DOM and payload hashing bypasses 100% of LLM model calls when content is unchanged. Reduces AI API costs and token consumption to near zero.
5 Verification Gates (G1–G5)
Candidate repairs must pass structural syntax, shape consistency, historical stability, independent semantic verification, and field continuity before human review.
Mandatory Human Approval
Foundational invariant: Model proposes, human decides. Repairs are never automatically activated. An explicit --by signature is enforced.
SQLite WAL Concurrency
Single-writer connection, multi-reader pool, content-addressed zstd snapshot compression, and atomic non-blocking VACUUM INTO live backups.
Local Web UI & MCP Server
Built-in browser dashboard served on loopback, plus 7 read-only inspection tools exposed over Model Context Protocol (MCP) for Claude Desktop, Cursor, and AI agents.

Quickstart in 60 Seconds

Get up and running locally with three simple commands.

STEP 1
Initialize Database
Creates SQLite schema with single-writer WAL mode and secure 0600 file permissions.
agentd init
STEP 2
Add Target Check
Declare target URL, semantic extraction intent, and DOM locator binding.
agentd check add price-chk \
  --url https://shop.com/item \
  --kind scalar --selector ".price" \
  --interval 1h
STEP 3
Start Server & Dashboard
Launches the background scheduler, REST API, and embedded Web Dashboard.
agentd serve
